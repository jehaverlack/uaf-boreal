Setup Google Client ID

BOREAL requires a Google OAuth Desktop Client ID to access Google Drive through Rclone.

1. Open Google Cloud Console

Choose an existing Google Cloud project or create a new project that you want to use for BOREAL.

BOREAL does not select a Google Cloud project for you. Google may display a recently used project, so confirm the project name before enabling APIs or creating credentials.

Choose or Create a Project

2. Enable the Google Drive API

  1. Click the button below to open the Google Drive API setup page.
  2. Confirm that Google shows the project you selected in step 1.
  3. Click Enable.

Open Google Drive API Setup

3. Configure Google Auth Platform

A new project must be registered with Google Auth Platform before Google allows you to create an OAuth client. Confirm that the project shown in the Google Cloud header is the project you selected in step 1, then:

  1. Click Get Started.
  2. Under App Information, enter BOREAL as the app name and select your support email.
  3. Under Audience, choose Internal only when the app will be used exclusively by members of your Google Workspace organization. Otherwise, choose External.
  4. Enter your contact email, accept the Google API Services User Data Policy, and finish creating the app.
  5. If you chose External and the app is in testing, open Audience and add the Google accounts that will use BOREAL as test users.

Open Google Auth Platform

4. Create the OAuth Client

After Google Auth Platform setup is complete, return to Clients.

  1. Open Clients.
  2. Create a new OAuth Client.
  3. Select Desktop app as the application type.
  4. Give the client a descriptive name such as BOREAL.
  5. Create the client.
  6. Click Download and save the generated JSON credentials file in your Downloads directory.

5. Import the Client ID into BOREAL

Select the JSON credentials file downloaded from Google.

The credentials will be stored locally in BOREAL's private configuration directory as google-client.json.
