Setup Google Client ID

Step 1 of 5

1. Open Google Cloud Console

Choose an existing Google Cloud project or create a new project for BOREAL.

Confirm the project name shown by Google before continuing. Google may open a recently used project.
Choose or Create a Project

2. Enable the Google Drive API

  1. Open the Google Drive API setup page.
  2. Confirm that Google shows the project selected in step 1.
  3. Click Enable.
Open Google Drive API Setup

3. Configure Google Auth Platform

Open Google Auth Platform for the project selected in step 1.

  1. If Google says the Auth Platform is not configured, click Get Started.
  2. Under App Information, set App name to BOREAL, select your User support email, and click Next.
  3. Under Audience, choose Internal for organization-only use; otherwise choose External. Click Next.
  4. Under Contact Information, enter your email address and click Next.
  5. Under Finish, accept the Google API Services User Data Policy, click Continue, and then click Create.
  6. If you chose External and the app is in testing, open Audience, click Add users, add every account that will use BOREAL, and click Save.
Open Google Auth Platform

4. Create the OAuth Client

  1. Open Clients and click Create client.
  2. Set Application type to Desktop app.
  3. Set Name to BOREAL.
  4. Click Create.
  5. Click Download JSON. If the creation dialog has closed, use the download action for BOREAL in the Clients list.
  6. Save the JSON credentials file in your Downloads directory.
Critical: Click Download JSON before closing the OAuth client dialog.
Open OAuth Clients

5. Import the Client ID into BOREAL

Select the JSON credentials file from your Downloads directory.

BOREAL stores the credentials locally in its private configuration directory as google-client.json.
